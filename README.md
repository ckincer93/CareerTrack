## Overview
CareerTrack is a full-stack Spring Boot web application designed to help users track job applications, interview progress, follow-up dates, salary ranges, and notes in a clean dashboard interface.

## Features
- Add job applications
- Edit existing applications
- Delete applications
- Track application status
- Store follow-up dates and salary information
- Dashboard card layout
- H2 database for local development
- PostgreSQL support for production deployment
- Basic Spring Boot testing

## Technologies Used
- Java 21
- Spring Boot
- Thymeleaf
- Spring Data JPA
- H2 Database
- PostgreSQL
- Maven
- Render
- Neon
